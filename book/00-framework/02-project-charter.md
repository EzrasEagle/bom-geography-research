# Project Charter — BoM Geography Research Atlas

## Dual track

1. **Models track** — Every major published geography model’s use of each relevant verse, with citations and “why.”
2. **Insights track** — Independent research (travel, climate, flora, hydrology, Spanish-era routes, paleoclimate data availability, etc.) that may help any reader evaluate models without belonging to one model.

## Products

| Product | Role |
| --- | --- |
| Hybrid data core | Markdown verse files + CSV/JSON catalogs |
| Book | Structural + sequential walkthrough with footnotes/appendices |
| App | Browse verses, models, insights; comparative views |
| Prompts | Natural-language specs so future AI can rebuild/improve the stack |
| Sync | GitHub (source of truth) + Google Drive backup |

## Reader principle

Present evidence so users can make up their own minds. Weight is transparent; advocacy is optional and labeled.
