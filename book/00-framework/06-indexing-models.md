# Indexing models into a richer framework

We will not perfectly pour any published model into our schema. Instead we use **Model Index Packs** (`research/models/indexes/<id>/`) and grow the taxonomy when native parameters appear.

## Start order
1. Internal (constraints)  
2. Sorenson-style limited Mesoamerica (densest external)  
3. Highland-emphasis Mesoamerica (micro diffs)  
4. Heartland  
5. Baja  

See `research/models/RICHNESS_RANKING.md` and `INDEXING_METHOD.md`.
