# Assumptions & user models

## Why assumptions are first-class
A claim like “Sidon is the Grijalva” is not raw scripture—it is an **identification assumption**. If the assumption changes, all dependent distance and war narratives shift.

## Assumption categories
See `research/schema/assumption.schema.json`: distance scale, direction convention, place ID, narrow neck, hydrology, climate, Cumorah, landing, language, genetics, archaeology, transport, terrain, etc.

## User model lifecycle
1. **Fork** a published model (or start from Internal-only).  
2. **Toggle/edit** assumptions.  
3. **Watch** Map Lab recolor constraints.  
4. **Tag** reader verses into the personal model.  
5. **Optionally share** the model package (JSON) for others to adopt pieces.

## Sharing & relevance heat
When many models (published or user) attach the same verse or insight, that item’s **reuse count** rises—signaling high comparative relevance, not automatic truth.
