# Index pack: Mesoamerican Highland-emphasis variants

**Richness rank:** 3 · **Completeness:** G0→G1  
**Tradition:** Limited Mesoamerica with **stronger highland emphasis** for Nephite core (e.g. highland Guatemala–centered Nephi / adjusted Zarahemla), sometimes distinguished from lowland-heavier Sidon placements.

## Why index separately from Sorenson-style
Same theater, different **micro place_mappings** and elevation assumptions. Perfect test of micro adjustment UI: swap place IDs without rewriting all verses.

## Note on naming
“Highland model” is not one single book brand—treat as a **family**. When a specific author (e.g. a named highland proposal) is harvested, add `authors:` and split subfolders if needed.
