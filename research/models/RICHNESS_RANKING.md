# Which models to start with (information density)

## Ranking for **framework bootstrapping**

| Rank | Model | Why | Best first use |
| --- | --- | --- | --- |
| **1** | **Internal geography** (text-only graphs; Clark-style relative maps; constraint papers) | Most *portable* into Map Lab: directions, days, adjacencies without GPS fights | Seed **constraints** + gazetteer |
| **2** | **Limited Mesoamerica / Sorenson-style** | Richest published apparatus: place lists, Alma 22 readings, maps, distance essays, cultural parallels (*Ancient American Setting*, *Mormon’s Map*, *Mormon’s Codex*) | Seed **place_mappings**, verse claims, assumptions |
| **3** | **Mesoamerican Highland variants** (highland-emphasized Nephi/Zarahemla placements within Mesoamerica) | Same theater as Sorenson-style but **different elevation/place IDs**—teaches *micro* mapping deltas | Diff against Sorenson-style pack |
| **4** | **Heartland** | Dense popular maps + Cumorah/Mississippi package; strong on some verses, thinner on others | Alternate **place_mappings** + archaeology evidence items |
| **5** | **Baja (Rosenvall-type)** | Strong climate/seed/peninsula package; excellent for landing & environment parameters | Climate/landing assumptions + fewer dense Alma city graphs |
| **6** | South America / Malay / others | Important for comparison; harvest after core five | Completeness, not bootstrap |

### Practical start order
1. **Internal** → pure constraints (framework spine)  
2. **Sorenson-style limited Mesoamerica** → densest external mappings + verse use  
3. **Highland Mesoamerica variant** → shows micro place swaps  
4. **Heartland** → second major external package  
5. **Baja** → climate-first package
