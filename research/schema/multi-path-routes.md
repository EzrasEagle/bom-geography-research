# Multi-path routes (not one static edge)

## Principle
Every historical march is its own **path** with waypoints. Paths may **share a trunk** then **branch**. Intended destination can differ from actual end.

## Limhi lost party (best model)
```
Nephi (start)
   │
   ▼
wilderness  ────── trunk shared with Zarahemla corridor (same general departure bearing)
   │
   ├─ branch point (lost / divergence)
   │         ╲
   │          ╲ ghost: intended Zarahemla
   ▼
Desolation (actual)
```

Do **not** replace this with a single straight Zarahemla→Desolation edge that absorbs all refs.
Keep Omni Mosiah path as a separate polyline on the same wilderness family.

## Later
Snap waypoints to rivers/ridges (Terrain Lab). Branch points become constraints on “where a wrong turn is possible.”
