# Soft corridors (wilderness)

## Principle
Wilderness is **not** a blob that engulfs cities. It is a set of **corridor bands along associations**:

- Nephi → toward Zarahemla (N days into wilderness from Nephi)
- Zarahemla → toward Nephi (N days from Zarahemla; does not fill the land)
- Optional branch legs (e.g. toward Desolation)

Adding associations **extends** wilderness only along those routes.

## Day rings
Radius = days × pixels/day × (terrain day-miles / open day-miles).  
Slower wilderness travel → smaller ring for the same “1 day.”

## Lands
“Land of Nephi” is larger than a pin; we don’t know the exit point. Later: expandable land polygons; corridor attaches to the **edge** facing the route.
