# Evidence domains

Beyond pure geographic phrases in the text, the workbench accepts tagged evidence in these domains. Each item needs citation + uncertainty.

| Domain | Examples | Caution |
| --- | --- | --- |
| `textual_geography` | Directions, days’ journey, seas, Sidon | Relative vs absolute |
| `climate_botany` | Seeds, timber, seasons | Modern irrigation ≠ ancient |
| `hydrology_topo` | Rivers, isthmuses, elevation | Sea-level and river course change |
| `archaeology_artifacts` | Cement, metallurgy, fortifications | Dating & cultural attribution debates |
| `language_onomastics` | Name etymologies, writing | Speculative chains common |
| `genetics` | Population continuity studies | Sampling bias; faith/science boundary |
| `historical_routes` | Spanish trails, indigenous corridors | Analogy only for 600 BC |
| `paleoclimate` | Lake cores, pollen ~600 BC | Sparse spatial resolution |
| `transport` | Ships, roads, no-roads assumption | Text rarely specifies roads |
| `culture_demography` | Population, urbanism | Highly model-dependent |

UI rule: never display genetics/language without an **uncertainty badge**.
